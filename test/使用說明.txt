更新方式（iPad／手機）
1. 在「檔案」App 解壓 ZIP。
2. 開原有 GitHub 儲存庫，進入原本 index.html 所在位置。
3. Upload files，上傳本包所有檔案並提交，覆蓋同名舊檔案。
4. 等 GitHub Pages 部署完成，用 Safari 開原網站重新整理。
5. 右上角帳戶 → 帳戶與設定 → 應用程式，查看版本 3.3.1。
6. 如果仍是舊版，先在設定使用「重新載入更新」，再完全關閉並重新開啟 PWA。
不需 functions 資料夾、不需電腦、不需 Node.js。不會升級付費方案。
舊 qrcode.js 已不再引用，可以刪除；不刪除也不影響新版。
