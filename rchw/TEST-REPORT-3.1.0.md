# StudyOS 3.1.0 驗證記錄

測試資料全部為模擬資料，沒有向正式帳戶發出邀請、通知或功課。

最終執行結果：**17 項通過、0 項失敗、0 項略過**；2026-09-05 執行。正式發佈版編譯及 JavaScript 語法檢查通過。

啟動修正：兩個編譯後的 classic script 原本重複宣告 Babel 的 `_excluded`，導致 SyntaxError。現將各檔完整編譯輸出隔離，並新增同一全域環境依次載入兩檔、確認 React 初始畫面輸出的回歸測試。資源網址及離線快取使用 hotfix1。

已使用 Firebase Firestore Emulator 執行服務及權限測試：

1. 明日日期跨月／跨年、完成、隱藏、撤回及非法日期。
2. 更新保留個人完成時間、私人筆記及隱藏記錄。
3. 五位帳戶編號唯一且固定；邀請未接受前不加入群組。
4. 關閉同步保留舊功課，重新開啟可補回且不重複。
5. 只同步新功課不補回舊項目，來源更新不取消個人隱藏。
6. 私人發放需接受，封鎖後不再接收新邀請。
7. 普通成員不能修改角色、撤回他人發放或使用總管理功能。
8. 重複請求只建立一個來源，兩人的完成狀態互相獨立。
9. 離開群組保留舊紀錄，停止新投遞及內容更新。
10. 申請加入審批、成員發放控制及總管理員凍結群組。
11. 客戶端不能列出帳戶編號、偽造帳戶／成員或偽造同步副本。
12. 同步副本只容許修改個人完成、筆記及隱藏等欄位。
13. 群組來源限制接收者讀取，離組撤銷存取，私人來源要求已接受。
14. 總管理員身份要求已驗證的電郵 token。

另有 React 靜態輸出測試：實際 Lucide 圖示格式、群組卡片、帳戶 QR、服務錯誤提示及重試入口。編譯檢查包含舊主程式及新增協作 JSX；發佈檔不需要瀏覽器即時編譯。

執行方式（需要 Node.js 22 及 Firebase 模擬器所需 Java）：

```bash
npm ci
npx firebase emulators:exec --only firestore --project demo-studyos 'npm test'
npm run build
```

直接 `npm test` 而沒有啟動模擬器，只會跑純函數及靜態輸出測試；服務及安全規則測試會標示略過，不能當成完整通過。
