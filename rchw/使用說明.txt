電子手冊 Pro · StudyOS v2.2.0 動態版

檔案內容
1. index.html：網站最終版。
2. manifest.webmanifest、icon.svg、sw.js：手機安裝及離線外殼支援，須與 index.html 放在同一層。
3. firestore.rules：建議的 Firebase 資料庫權限規則。

部署前檢查
1. 將壓縮檔內全部檔案上傳至 GitHub Pages 或 Firebase Hosting 的同一目錄。
2. 到 Firebase Authentication 開啟 Google 及 Email/Password 登入。
3. 在 Authentication > Settings > Authorized domains 加入網站網域。
4. 到 Firestore Database > Rules，貼上 firestore.rules 內容並發佈。
5. 管理員帳戶為 chimhinhin@gmail.com。

重要說明
- Firebase 前端 API Key 會出現在網頁原始碼，這是正常做法；資料安全由登入、Firestore Rules 及授權網域控制。
- 套用新規則前，建議先用 Firebase Rules Playground 測試管理員及學生帳戶。
- 新版保留原有 users、users_public、public_assignments、system_settings 資料結構。
- 舊功課不會因為升級而刪除，新版亦已取消「到期兩日後自動刪除」。

主要操作
- 主頁優先顯示「明天要交」的未完成功課；「今日尚餘」只計算今日到期的功課。
- 主頁右下角「＋」：新增功課或測驗。
- 任務工具列「歷史」：切換已完成紀錄。
- 月曆：按日期查看及修改當日紀錄。
- 班級：使用六位班級代碼加入；班級分頁旁的離開按鈕可退出班級。
- 時間表編輯：分為時間設定及課程編排，離開前會提醒未儲存修改。
- 通知中心：可切換全部／未讀，亦可一鍵標示全部已讀。
- 應用程式設定：設定分類可展開或收合，保留完整自定義選項。
- 超級管理中心：手機採用橫向分頁，iPad 及桌面使用側欄。
- 設定 > 匯出備份：下載個人 JSON 備份。
- 動態效果：主頁卡片、數字、進度、頁面切換、通知、時間表與後台均加入流暢轉場。
- 如不需要動畫，可在「設定 > 使用體驗」開啟「減少動畫」。

確認新版
- 網站頂部日期右邊應顯示「v2.2.0」。
- 設定頁頂部應顯示綠色「v2.2.0 動態版」。
- 如果仍看到舊版，請確保上傳壓縮檔內全部檔案，然後重新整理網站；已加到主畫面的版本可先關閉再重新開啟。
