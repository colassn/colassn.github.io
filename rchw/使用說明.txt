StudyOS 3.1.0 — 所有檔案同一層

hotfix1：修正編譯檔重複宣告變數導致無法啟動。請一併覆蓋 index.html、
app.js、collaboration.js、sw.js（建議上傳整包對應檔案），等待網站部署完成
再重新整理；若仍見舊畫面，關閉該網站分頁／PWA 後重新開啟並重新整理。

ZIP 內沒有子資料夾，也沒有內藏 ZIP。全部檔案解壓到同一個資料夾即可。
程式入口：index.html。其他檔案自動載入，不用逐個開啟。

平時不用打開 app-source.html（開發原始碼）、server.js（後端入口）、
service.js、測試檔或設定檔。它們與網站檔案放在同一層。

首次設定及正式使用
Google 登入、多人群組及 PWA 仍需要先部署網站和 Firebase 後端。
本次只改檔案擺放，沒有取消 Functions，也沒有替你部署。
部署後，平時只需開網站網址；直接雙擊本機 HTML 不能代替部署。

在此資料夾使用 Node.js 22 執行：
  npm ci
  npx firebase login
  npx firebase deploy --project recordhwv2 --only functions:studyos-collaboration,firestore:rules,firestore:indexes
  npx firebase deploy --project recordhwv2 --only hosting

Firebase 設定已指向同一個資料夾，並排除後端、測試及原始碼，避免上傳到公開網站。
部署前保留原有資料和規則；已有其他索引時，請合併設定，不要刪除無關索引。
Functions 仍需合適的 Firebase 方案。套件没有管理金鑰或登入憑證。
npm ci 本身會由套件管理器建立 node_modules；它不在交付 ZIP 內，不用手動開啟。

若用其他網站空間，只上傳以下網站檔案，不要整包全部公開：
  index.html、app.js、collaboration.js、collaboration.css、core.js、
  react.js、react-dom.js、lucide.js、qrcode.js、tailwind.css、
  sw.js、manifest.webmanifest、icon.svg

日後修改原始碼後：npm run build
測試：npx firebase emulators:exec --only firestore --project demo-studyos 'npm test'

本版保留 3.1.0 功能：五位帳戶編號、群組邀請、人人發放、個人同步、
草稿、通知、私人筆記及總管理。同步關閉保留舊功課，更新保留完成狀態。
來源相同的重複同步不會新增副本；多群組分別發放則是各組獨立來源。
原有正式環境、真機 iPad 和 PWA 登入仍需要部署後驗收。
