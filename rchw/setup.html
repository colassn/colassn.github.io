免費版設定指南

呢個版本只用 GitHub Pages、Firebase Authentication 同 Firestore 免費額度，唔需要 Cloud Functions、Node.js 或付款資料。

只需做一次

  1. 開啟 Google 登入
    Firebase Console → Authentication → Sign-in method → Google → 啟用。
  2. 建立 Firestore Database
    選擇 Production mode；地區按你原本嘅 Firebase 專案設定即可，保持 Spark 免費方案。
  3. 發佈免費版規則
    按下面「複製規則」，到 Firestore Database → Rules 全選原有內容，貼上後按 Publish。
  4. 加入授權網域
    Authentication → Settings → Authorized domains，加入 colassn.github.io（如果你用其他 GitHub Pages 網址，就加入該網域）。
  5. 重新開啟網站
    上傳整包檔案後，先用 Safari 網頁登入一次，再用分享 → 加入主畫面。新版本會自動建立五個英文字母帳戶編號。

免費版規則

規則會保留原有個人功課及班級資料，同時開啟新的 Spark 群組功能。唔好自行刪除其他規則段落。

如果首次開啟群組要求建立索引

按錯誤訊息內的「建立索引」連結，等待 Firebase 建立一次即可；呢個索引唔會收費。套裝內亦附有 firestore.indexes.json 供日後由電腦部署。

如果「協作服務暫時無法」

先確認已按 Publish，並等大約一分鐘，再在網站設定頁按「重新連接」。如果仍然失敗，關閉舊 PWA 後用 Safari 網頁重新開啟；瀏覽器可能仍保留上一版離線快取。

你會得到嘅功能

每人都可以建立群組及發放功課；用五個英文字母帳戶編號邀請其他人；對方接受後才加入個人手冊；「同步到個人」可逐個群組開關；完成狀態、私人筆記及隱藏記錄各自保存；總管理員仍可凍結帳戶或群組。

Spark 免費額度由 Firebase 每日重設。呢個版本唔會自動開啟付費方案。
